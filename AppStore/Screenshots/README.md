# Draft tvOS screenshots

Captured from version 1.0.0 (1) on the tvOS 27 simulator on 23 October 2026.
Both files are unmodified 1920×1080, 8-bit RGB PNGs without an alpha channel.

- `en-US/01-source-picker.png`: the native source picker with network discovery
  disabled by the unit-test launch environment; no private source names appear.
- `en-US/02-fullscreen-reception.png`: real decoded 1080p30 video from the local
  official OMT SDK test-pattern fixture, with the playback controls hidden.

The test pattern is original repository artwork. These images show simulator
behaviour, not physical Apple TV performance or a latency measurement. Review
these draft assets against the final submitted build before uploading to Apple.
